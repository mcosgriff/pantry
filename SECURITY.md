# Security policy

## Reporting a vulnerability

Please report it privately through GitHub:
[Report a vulnerability](https://github.com/mcosgriff/pantry/security/advisories/new) (the "Security" tab,
then "Report a vulnerability"). Don't open a public issue for it.

Pantry is maintained by one person in their own time, so there is no fixed response time; a report will be
acknowledged as soon as it is read, and a fix goes out as a normal release, which Obtainium picks up.

## What counts

For example:

- data leaving the phone that the app doesn't say it sends;
- a tracker, or a permission the app doesn't explain, in a release APK;
- a release APK that wasn't built from this repo.

## Supported versions

Only the latest release gets fixes.
